---
name: mockup-sandbox generated module map is untracked
description: Why artifacts/mockup-sandbox/src/.generated/ is gitignored and must not be re-added
---

`artifacts/mockup-sandbox/src/.generated/mockup-components.ts` is auto-generated by `mockupPreviewPlugin.ts` and regenerated on every dev-server start.

**Rule:** It is untracked (in `.gitignore` under `artifacts/mockup-sandbox/src/.generated/`). Do NOT re-add it to git.

**Why:** When tracked, it conflicted on essentially every rebase — different agents add mockup modules in different orders, so the module-map entries reorder/duplicate constantly. Each rebase forced a manual dedup-union resolution, and accepting either side just reproduced the conflict on the next rebase.

**How to apply:** If it reappears as tracked and conflicting during a rebase, resolve to the deduplicated union to finish the rebase, then `git rm --cached` it and confirm the `.gitignore` entry still exists. Never commit it.
