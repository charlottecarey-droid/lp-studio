Build a polished, production-quality React + Tailwind template called “1:1 Account Microsite.”

This should be a buyer-facing ABM microsite that sales and marketing teams can create for a specific target account. It should feel like a premium personalized sales story, not a dashboard, CRM record, or generic landing page.

The page should help an account understand:

* Why this matters
* Why now
* What is relevant to their business
* What value applies to each stakeholder
* What proof supports the recommendation
* What resources they should review
* What the next step is

The template should customize dynamically based on:

1. Account
2. Persona
3. Funnel stage
4. Use case
5. Campaign source / UTM parameters
6. Salesforce fields
7. Manual content overrides

The final result should demonstrate that LP Studio templates are not static landing page layouts. They are dynamic campaign systems that can personalize based on account context, buyer role, sales stage, and campaign logic.

Default example:

* Account: LP Studio Enterprise
* Industry: B2B SaaS
* Segment: Enterprise
* Persona: Marketing
* Funnel stage: Engaged
* Use case: ABM account pages

Design direction:

* Premium B2B SaaS / enterprise microsite
* Editorial, spacious, warm, and polished
* Cream/light background with deep navy, indigo, and subtle coral accents
* Strong typography
* Large sections with breathing room
* Minimal but elegant cards
* High-quality buyer-facing experience
* No visible internal demo controls
* No dashboard clutter
* No fake admin panels on the visitor-facing page
* No obvious “Hi {{First Name}}” personalization
* The page should feel strategically tailored, not mail-merge personalized

Important:

* The page should NOT show internal controls to the visitor.
* Stage, persona, account, use case, and content variation should be determined behind the scenes through config, URL parameters, SFDC-style fields, or manual overrides.
* Admin/editor logic can exist in the code/config, but do not display it on the page.
* The page should feel like something an AE, BDR, or marketer would confidently send to a real enterprise buyer.

Technical requirements:

* Use React and Tailwind CSS
* Use clean reusable components
* Frontend-only
* No external APIs
* No external images
* Use placeholder logos, initials, and UI graphics
* Use lucide-react icons if available
* Fully responsive
* Put all editable content in a config object
* Include clear data structures for account fields, personas, funnel stages, resources, proof, CTAs, and override rules
* Ensure it runs successfully in Replit
